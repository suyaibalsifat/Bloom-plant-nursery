# 🌿 Bloom — Plant Nursery Online Shop

A simple full-stack e-commerce site for a fictional sustainable plant nursery.

## Features
- Home page with hero and featured plants
- Shop page with 15 plants, filters, and sorting
- Product detail with reviews
- Shopping cart (localStorage)
- Checkout with order confirmation
- About and Contact pages
- Fully responsive

## Tech Stack
- Frontend: HTML, CSS, Vanilla JS
- Backend: Node.js + Express
- Templating: EJS
- Data: JSON files

## Run Locally
```bash
npm install
npm start
```
Then open http://localhost:3000
